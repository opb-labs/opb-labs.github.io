# De cero a Orderflow · OPB Labs

Curso gratuito para aprender trading de futuros del Nasdaq (NQ) y del S&P 500 (ES), desde cero hasta orderflow.

## Archivos

| Archivo | Qué es |
|---|---|
| `index.html` | Portada del curso |

| `assets/logo.svg` | Logo de OPB Labs (también se usa como icono de la pestaña) |
| `.nojekyll` | Le dice a GitHub Pages que publique los archivos tal cual |

## Cómo publicarlo gratis en GitHub Pages (sin terminal)

1. Crea una cuenta en https://github.com (si no tienes una).
2. Arriba a la derecha, pulsa **+ → New repository**.
   - Nombre del repositorio: `TU-USUARIO.github.io` (con tu nombre de usuario exacto). Así la web queda en `https://TU-USUARIO.github.io`.
   - Si prefieres otro nombre, por ejemplo `curso-orderflow`, la web quedará en `https://TU-USUARIO.github.io/curso-orderflow`.
   - Márcalo como **Public** y pulsa **Create repository**.
3. En la página del repositorio, pulsa **uploading an existing file** (o **Add file → Upload files**).
4. Descomprime el ZIP en tu ordenador y arrastra **todo el contenido** de la carpeta (no la carpeta en sí): `index.html`, `curso.html`, `README.md`, `.nojekyll` y la carpeta `assets`.
   - El archivo `.nojekyll` está oculto en Mac y Windows. Si no lo ves, no pasa nada: la web funciona igual sin él.
5. Pulsa **Commit changes**.
6. Ve a **Settings → Pages**. En **Source**, elige **Deploy from a branch**, rama **main** y carpeta **/ (root)**. Pulsa **Save**.
7. Espera 1–2 minutos y recarga. Arriba aparecerá: *Your site is live at…* con tu enlace.

## Cómo actualizarlo

Sube el archivo modificado con **Add file → Upload files**, usando el mismo nombre. GitHub lo sustituye y la web se actualiza en un par de minutos.

## Dominio propio (cuando quieras)

1. Compra un dominio (por ejemplo `opblabs.com`).
2. En **Settings → Pages → Custom domain**, escribe el dominio y pulsa **Save**.
3. En el panel de tu proveedor de dominio, crea los registros DNS que indica la ayuda de GitHub Pages ("Managing a custom domain for your GitHub Pages site").
4. Marca **Enforce HTTPS** cuando esté disponible.
